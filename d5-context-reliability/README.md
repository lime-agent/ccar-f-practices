# D5 — Context Management & Reliability (15%)

## 실습 목표
- Lost-in-the-Middle 대응: 중요 정보를 앞/뒤 배치, 섹션 헤더 구분.
- 요약 시 수치(금액·날짜·번호) 보존 패턴을 구현한다.
- 에스컬레이션 기준 프롬프트를 작성한다(즉시 vs 금지 케이스 구분).
- 구조화된 에러 전파 컨텍스트를 설계한다.

## 시드 (세션에서 함께 추가)
- `escalation_prompt.py` — 에스컬레이션 기준 명시 프롬프트
- `context_trim.py` — 수치 보존 요약

## 핵심 정리
- 에스컬레이션 = 사람 요청·정책 공백·진전 불가 (감정/자신감 점수 ❌)
- 상충 정보는 임의 선택 금지 → 둘 다 출처와 함께 보고
