# backend/ 전용 규칙 (디렉토리 계층 — 우선순위 ↑)

`backend/` 안에서 작업할 때 **추가로** 적용되는 규칙이다.
**더 가까운 파일이 우선**하므로, 여기 규칙이 루트 `CLAUDE.md`와 충돌하면 이 파일이 이긴다. (Task 3.1)

## backend 규칙
- 모든 외부 입력은 경계(boundary)에서 검증
- DB 접근은 repository 계층으로만 (직접 쿼리 금지)
- 비밀은 코드에 하드코딩 금지 — 환경변수 참조

> **실습 확인(3.1)**: `backend/` 에서 Claude Code 세션을 열고 `/memory` 로
> 이 파일이 루트 `CLAUDE.md`와 **함께** 로드되는지, 충돌 시 어느 쪽이 우선인지 관찰.
